## 6.1 อัตลักษณ์ภาพ (Art Direction): 2D Neon Sci-Fi

| องค์ประกอบ | รายละเอียด |
|---|---|
| **สไตล์ภาพ** | 2D สีสัน Neon บนฉากมืด (ท้องฟ้ายามค่ำคืน/อวกาศ) — เส้นเรืองแสง, เอฟเฟกต์ glow |
| **จานสีหลัก** | พื้นหลังมืด `#0B0F2A` · Neon ฟ้า `#00E5FF` · Neon ชมพู/ม่วง `#FF2E97` · Neon เขียว (ถูกต้อง) `#39FF14` · Neon แดง (คำใบ้/ผิด) `#FF3B3B` · เหลืองพลังงาน `#FFD700` |
| **ตัวอักษร** | หัวข้อ: ฟอนต์หนา Sci-Fi (เช่น Orbitron/Baloo + ฟอนต์ไทยหนา) · เนื้อหา: อ่านง่าย ขนาด ≥ 18px |
| **Sprite แอนิเมชัน** | มอนสเตอร์: ชุดเฟรมเดิน/กระโดด, แอนิเมชันระเบิด (ถูกต้อง = ระเบิดสีเขียว เปลี่ยนเป็นมิตร), กระสุนเรืองแสง |
| **เสียง** | SFX ยิง/ระเบิด/ถูก-ผิด + BGM เร้าใจแบบ 8-bit/synthwave; ปิดได้ใน Settings |

## 6.2 หลักการออกแบบ UX สำหรับเด็กอายุ 8–10 ปี

1. **เป้าหมายชัดเจน** — แสดงคำของมอนสเตอร์ตัวที่เดินเข้ามา + แถบมาตรา (8 ปุ่มกระสุน) ตลอดเวลา
2. **ปุ่มใหญ่ ระยะห่างพอดี** — ปุ่มกระสุน ≥ 44×44 px เรียง 1–8 ล่างจอ, เมาส์/แตะง่าย
3. **ลดข้อความยาว** — ใช้สี+ไอคอน+ตัวอักษรสั้น; คำอธิบายเหตุผลอยู่ใน "สมุดรหัส" ที่เปิดได้
4. **ผลป้อนกลับทันที** — ถูก = ระเบิดเขียว+เสียงสำเร็จ / ผิด = ชะงัก+คำใบ้แดง+เสียงผิด
5. **ไม่ทำให้เด็กรู้สึกผิด** — ผิดคือโอกาสเรียนรู้ ไม่มี Game Over น่ากลัว (มีโหมดผ่อนปรน)
6. **จังหวะ 3 นาที** — แสดงตัวนับเวลาถอยหลังชัดเจน + เตือน 30/10 วินาทีสุดท้าย
7. **Tutorial แบบฝังในเกม** — ด่าน 1 สอนยิงด้วยลูกศรชี้ + ข้อความสั้น (ไม่ใช่หน้าเอกสาร)

## 6.3 โครงสร้างหน้าจอ (Screen Map) และ Modal

| หน้าจอ | ฟังก์ชัน | หมายเหตุ |
|---|---|---|
| 1. หน้าโหลด/โลโก้ | Branding + โหลดทรัพยากร | สั้น ≤ 3 วิ |
| 2. หน้าหลัก (Hub) | เริ่มเกม / โหมด AR / การ์ด AR / ตั้งค่า / Hall of Fame | Neon sci-fi |
| 3. เลือกด่าน | แผนที่ภารกิจ 8 ด่าน (ล็อกตามความคืบหน้า) + ดาวสะสม | |
| 4. เกมหลัก | ฉากยิง: ยาน, มอนสเตอร์, กระสุน 8 ชนิด, HUD (เวลา/คะแนน/HP) | Canvas หลัก |
| 5. สรุปรอบ | คะแนน, ความแม่นยำ, ดาว, ชิ้นส่วนอัปเกรด, ปุ่มเล่นอีกครั้ง | Modal |
| 6. โรงเก็บยาน (Hangar) | อัปเกรดยานด้วยชิ้นส่วน (เครื่องยนต์/ปืน/โล่) | |
| 7. โหมด AR | กล้อง + การ์ดมอนสเตอร์บนโต๊ะ + ปุ่มกระสุนมาตรา | AR.js |
| 8. **Modal Settings** | เสียง (BGM/SFX แยก), ความเร็วเกม (ช้า/ปกติ/เร็ว), โหมดผ่อนปรน, ภาษา | Esc เปิด/ปิด |
| 9. **Modal Hall of Fame** | ตาราง 10 อันดับ (ชื่อในเกม, คะแนน, ด่านสูงสุด) — ดีไซน์สวยงาม เรืองแสง | |

## 6.4 ระบบไอคอน ป้าย และคำแนะนำ

- **ปุ่มกระสุน 8 ชนิด:** เรียง 1–8 ล่างจอ — สี/ไอคอนเฉพาะรายมาตรา (เช่น กก = รูปกุญแจ?, ใช้ตัวอักษรมาตราเป็นหลักกำกับชัดเจน) + ป้ายแป้นพิมพ์ตัวเลข
- **HUD:** เวลาถอยหลัง (มุมบน), คะแนน + ตัวคูณ, HP ยาน, ชิ้นส่วนที่สะสม
- **ป้ายมอนสเตอร์:** บัตรคำเหนือหัว — ตัวสะกดกะพริบเป็นเป้าหมาย; คำใบ้แดง "ออกเสียงเหมือน ก สะกด"
- **เอฟเฟกต์:** การเปลี่ยนเป็นมิตร (ประกายดาว), ระเบิด (particle), เส้นเล็ง (crosshair)
- **โหมด Colorblind-safe:** ถูก/ผิด ใช้ทั้งสี + ไอคอน (✓/✗) + เสียง

## 6.5 การออกแบบเพื่อทุกคน (Accessibility — WCAG 2.1 AA)

| ด้าน | ข้อกำหนด |
|---|---|
| ข้อความ | Contrast ≥ 4.5:1, ปรับขนาดตัวอักษรได้, ฟอนต์ไทยครบ |
| การควบคุม | เมาส์ + คีย์บอร์ด + สัมผัส; ใช้ปุ่ม 1–8 หรือคลิกก็ได้ |
| ประสาทสัมผัส | ทุกคำใบ้/เฉลยมีทั้งข้อความและเสียง; ปิดเสียงแล้วเล่นได้ครบ |
| ลดแสงกะพริบ | หลีกเลี่ยงแสงกะพริบรุนแรง (Photosensitive epilepsy) — ตั้งค่า "ลดเอฟเฟกต์" |
| ความเร็ว | โหมดช้า (ลดความเร็วมอนสเตอร์/ขยายเวลาตอบ) สำหรับผู้เรียนช้า |
