# 🃏 สเปกการ์ด AR — โหมดสแกน (Monster Speller)

> **ไฟล์:** `design/ar-cards/ar-cards-spec.md` · **อ้างอิง:** บทที่ 4.6 (การควบคุม AR) · 6.6 (สินทรัพย์) · 7.2 (AR.js)
> **วัตถุประสงค์:** การ์ดพิมพ์ (Physical card) ที่ผู้เรียนสแกนด้วยกล้องแล้วเห็นมอนสเตอร์จำลองบนโต๊ะ และยิงกระสุนมาตราเพื่อเปลี่ยนเป็นมิตร — เชื่อมโลกจริงกับเนื้อหาการเรียน

---

## 1) ภาพรวม

| รายการ | ค่า |
|---|---|
| จำนวนแบบการ์ด | **8 แบบ** (เผื่อลดเหลือ 4 แบบในด่านแรกได้) |
| เนื้อหาต่อการ์ด | 1 มาตรา (จาก 8 มาตรา) + มอนสเตอร์ประจำมาตรา + คำตัวอย่าง ตรง/ไม่ตรงมาตรา |
| ขนาดการ์ด | **A5 (148 × 210 มม.)** พิมพ์บน A4 (2 การ์ด/แผ่น) |
| ขนาดมาร์กเกอร์ | **80 × 80 มม.** (สแกนได้ระยะ 20–80 ซม.) |
| เทคโนโลยีมาร์กเกอร์ | **AR.js Barcode marker (ArUco original)** — ID 0–7 |
| ระยะสแกน | 20–80 ซม. · มุมเอียงกล้อง ≤ 30–45° |

## 2) จำนวนแบบและตารางแมป ID (หัวใจของโหมด AR)

| ID | มาตรา | มอนสเตอร์ประจำการ์ด | คำตัวอย่าง (ตรงมาตรา) | คำตัวอย่าง (ไม่ตรงมาตรา) |
|---|---|---|---|---|
| 0 | แม่กา | "กายักษ์" (ไม่มีตัวสะกด) | ตา, มา, นา, ฟ้า | — |
| 1 | แม่กก | "ก็อบลินกก" | มาก, เด็ก, จัก | สุข (ข), โรค (ค), เมฆ (ฆ) |
| 2 | แม่กด | "ดราก้อนด" | วัด, บิด, อาด | ชาติ (ช), โอกาส (ส), ปราสาท (ท), วิเศษ (ษ) |
| 3 | แม่กบ | "กบยักษ์" | กบ, ลาบ | บาป (ป), ภาพ (พ), โลภ (ภ), กราฟ (ฟ) |
| 4 | แม่กน | "นกยักษ์" | บ้าน, ทาน, ดิน | ผล (ล), การ (ร), จันทร์ (ร์), กาฬ (ฬ) |
| 5 | แม่กม | "หมีม" | ลม, ความ | — |
| 6 | แม่เกย | "มังกรเกย" | ไทย, ยาย, รวย | — |
| 7 | แม่เกอว | "วาฬเกอว" | ขาว, แมว, หาว | — |

> **หมายเหตุ:** คำตัวอย่างต้องผ่านการตรวจโดยครูภาษาไทย (IOC) ก่อนพิมพ์จริง — ตามบทที่ 3.3/10.2

## 3) รูปแบบมาร์กเกอร์ (AR.js)

### เลือก Barcode marker (ArUco) แทน Pattern marker

| เกณฑ์ | Barcode (ArUco) ✅ | Pattern (.patt) |
|---|---|---|
| สร้างง่าย/จำนวนมาก | ✅ สร้างด้วยโค้ด/โปรแกรม (ID ตัวเลข) | ต้องสร้างผ่าน Marker Generator ทีละแบบ |
| ความแม่นยำ | ✅ สูง มาร์กเกอร์ต่าง ID ไม่สับสน | กลาง |
| ขนาดไฟล์/ทรัพยากร | ✅ หนึ่งมาร์กเกอร์ = 1 ID เท่านั้น | ต้องมีภาพ + .patt |
| เหมาะกับ | ✅ การ์ดชุด 8+ ใบแบบนี้ | งาน AR งานเดียว/รูปภาพเฉพาะ |

### ข้อกำหนดมาร์กเกอร์ (บังคับ)

| ข้อกำหนด | รายละเอียด |
|---|---|
| รูปแบบ | AR.js Barcode **6×6** (ArUco original dictionary) |
| ID | 0–7 (ตามตารางข้อ 2) |
| สี | **ดำ 100% (#000000)** บนพื้น **ขาว 100% (#FFFFFF)** เท่านั้น — ห้ามสี/ไล่เฉด/เงา |
| ขอบดำ | มาร์กเกอร์ ArUco มีขอบดำโดยโครงสร้าง — ต้องมี **ขอบขาวรอบมาร์กเกอร์ ≥ 5 มม.** เสมอ |
| ความละเอียด | PNG ≥ 400×400 px (พิมพ์ 80 มม. → ≥ 127 dpi) |
| การย่อ/ขยาย | พิมพ์ **ขนาดจริง 1:1** (100%) — ห้ามบีบ fit-to-page |
| พื้นผิว | **เคลือบด้าน (matte)** — ผิวมันวาวสะท้อนแสงทำลายการจดจำ |

## 4) เลย์เอาต์การ์ด (A5 แนวตั้ง 148 × 210 มม.)

```
┌────────────────────────────────┐
│  แถบสี Neon ประจำมาตรา (ขอบบน 4 มม.)      │ ← สีของมาตรา (เช่น กก = ฟ้า, กด = ชมพู…)
│                                │
│   ┌────────────────────────┐  │
│   │                        │  │
│   │     มาร์กเกอร์ 80×80   │  │ ← ตรงกลางช่วงบน (ขอบขาวรอบ ≥ 5 มม.)
│   │     (ID 0–7)           │  │
│   └────────────────────────┘  │
│                                │
│     👾 มอนสเตอร์ประจำการ์ด      │ ← อาร์ต 2D Neon (Sprite เดียวกันกับในเกม)
│     มาตรา: แม่กก              │ ← ตัวอักษรใหญ่ ชัดเจน
│                                │
│   คำตรงมาตรา: มาก · เด็ก · จัก  │
│   คำไม่ตรง:   สุข · โรค · เมฆ   │ ← แยกสี: ตรง = ขาว, ไม่ตรง = เหลือง
│                                │
│   [ไอคอน] สแกนแล้วยิงมาตราให้ถูก  │ ← วิธีใช้ 1 บรรทัด
│   [โลโก้ MONSTER SPELLER]      │ ← เล็ก มุมล่าง
└────────────────────────────────┘
```

**ลำดับการรับรู้ของเด็ก (อ่านบนลงล่าง):** มาร์กเกอร์ (เป้าหมายสแกน) → ตัวละคร/มาตรา → คำตัวอย่าง → วิธีใช้

## 5) วิธีพิมพ์ (Printing Guide)

| ขั้นตอน | รายละเอียด |
|---|---|
| ไฟล์พิมพ์ | `printable-card-sheet.html` (A4 — 2 การ์ด A5/แผ่น, มีเส้นตัด) |
| เครื่องพิมพ์ | **เลเซอร์ขาวดำ/สี** ดีที่สุด (คมชัด); อิงค์เจ็ทเลือก "พิมพ์คุณภาพสูง" |
| การตั้งค่าพิมพ์ | ขนาด **100% / ขนาดจริง**, ปิด "fit to page", ไม่ย่อขยาย, เปิดขอบ (ไม่ใช่ borderless) |
| กระดาษ | 120–160 gsm (หนาพอวางบนโต๊ะ ไม่โค้งงอ); ไม่ใช้กระดาษมันวาว |
| เคลือบ | **เคลือบด้าน (matte lamination)** — กันน้ำ กันขอบงอ; ห้ามเคลือบมันถ้าเลี่ยงได้ |
| การตัด | ตัดตามเส้นประด้วยคัตเตอร์/กรรไกร — อย่าตัดล้ำเข้าโซนมาร์กเกอร์ |
| สำรอง | พิมพ์อย่างน้อย **2 ชุด** (ชุดใช้ในห้อง + ชุดสำรอง) + ไฟล์ดิจิทัล |

## 6) เงื่อนไขแสงและการใช้งาน (Lighting & Usage)

| เงื่อนไข | ค่า/คำแนะนำ |
|---|---|
| แสงสว่าง | **300–500+ lux** (ห้องเรียนปกติ) — แสงน้อย → เกมแสดง "เพิ่มแสง" (บทที่ 7.7) |
| แสงสะท้อน | หลีกเลี่ยงแสงจากหน้าต่าง/หลอดไฟส่องตรงการ์ด; ปรับมุมการ์ดให้สว่างสม่ำเสมอ |
| ระยะสแกน | 20–80 ซม. (มาร์กเกอร์ 80 มม.) — ใกล้เกิน/ไกลเกิน ระบบแจ้งเตือน |
| มุมกล้อง | ตั้งฉากกับการ์ด ±30–45° (เอียงได้ไม่เกิน); อย่าถ่ายเฉียงมาก |
| กล้อง | ≥ 720p; สมาร์ตโฟน/แท็บเล็ต/เว็บแคมคอมพิวเตอร์ |
| การถือ | มือไม่บังมาร์กเกอร์; พื้นการ์ดเรียบ (วางบนโต๊ะ) |
| ในเกม | มอนสเตอร์ 3D/2D ปรากฏเหนือการ์ด → เลือกกระสุนมาตรา (1–8) → ยิง → ถูก = เป็นมิตร / ผิด = คำใบ้ |

> ⚠️ **Fallback (สำคัญ):** เล่นไม่ได้ด้วยเหตุแสง/กล้อง/สิทธิ์ → เล่นโหมดจอปกติได้เต็มรูปแบบ (บทที่ 4.6, 7.8)

## 7) วิธีสร้างมาร์กเกอร์จริง

### ทางเลือก A — สคริปต์ OpenCV (แนะนำ, สร้างได้ 8 ID พร้อมกัน)
ไฟล์ `generate-markers.py` ในโฟลเดอร์นี้ — ต้องติดตั้ง `opencv-python-headless` ก่อน:
```bash
pip install opencv-python-headless
python generate-markers.py
```
- สร้าง `markers/marker-0.png` … `marker-7.png` (400×400 px, ArUco **DICT_ARUCO_ORIGINAL** — ตรงกับ AR.js barcode 6×6)
- ฝังลงเทมเพลตพิมพ์อัตโนมัติ (วางไฟล์ลงโฟลเดอร์ `markers/` ตามชื่อที่ HTML อ้างอิง)

### ทางเลือก B — Official AR.js Marker Generator (ออนไลน์)
1. เปิด https://jeromeetienne.github.io/AR.js/three.js/examples/marker-training/examples/generator.html
2. เลือก **Barcode marker** → ขนาด **6x6** → ใส่ ID 0–7 → Generate → ดาวน์โหลด PNG
3. วางไฟล์เป็น `markers/marker-{id}.png` แล้วเปิด `printable-card-sheet.html` (ตัวอย่างจะแสดงมาร์กเกอร์จริง)

> **ในโค้ดเกม:** กำหนด barcode ID ด้วย `barcodeValue: <id>` (0–7) ใน marker handler ของ AR.js — ดูบทที่ 7.2/7.4

## 8) เช็กลิสต์ QA ก่อนพิมพ์จำนวนมาก

- [ ] มาร์กเกอร์ทุกใบเป็นขาวดำ 100% ไม่มีเงา/สีเจือปนในโซนมาร์กเกอร์
- [ ] พิมพ์ที่ 100% — วัดมาร์กเกอร์จริงได้ 80×80 มม. ± 2 มม.
- [ ] สแกนทดสอบทั้ง 8 ID ด้วยสมาร์ตโฟน (ระยะ 20–80 ซม., แสง 300+ lux) → เจอครบ
- [ ] ID ไม่สลับกัน (สแกนการ์ด ID 3 ต้องขึ้นมอนสเตอร์ "กบยักษ์" มาตราแม่กบ)
- [ ] หลังเคลือบด้าน ยังสแกนติดปกติ
- [ ] ครูภาษาไทยตรวจคำตัวอย่างถูกต้องครบทุกการ์ด (IOC)
- [ ] มีชุดสำรอง + ไฟล์ PDF/HTML สำรอง
